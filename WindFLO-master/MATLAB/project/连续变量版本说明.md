# WindFLO 连续变量版本说明

## 1. 保留内容

原有离散随机键程序、`main_large_scale.m`、`results_large_scale/` 实验数据和已有图表均保留。连续版使用新的主程序和结果目录，不会覆盖旧结果。

## 2. 输入与输出

### 算法输入

```matlab
problem.representation = 'continuous';
problem.dimension = 2*model.nTurbines;
problem.lower = zeros(1,problem.dimension);
problem.upper = ones(1,problem.dimension);
```

对于100台风机，一个体是 `1×200` 向量。第 `2i-1` 个变量是第 `i` 台风机的归一化 x 坐标，第 `2i` 个变量是归一化 y 坐标。

### 评价输出

```matlab
fitness = [-AEP, LCOE, CVaR95];
layout  = N×2实际坐标;
detail.repair = 修复次数、移动量、最小间距和兜底次数;
```

## 3. 约束修复

1. 先把坐标限制在场界内。
2. 对进入矩形障碍物的点，移动到最近障碍物边界。
3. 对距离小于 `8R` 的风机对，沿两点连线反向各移动一半重叠距离。
4. 若连续排斥到达最大迭代数后仍有冲突，将冲突点移到距原位置最近的可行网格点。该步只是兜底。

## 4. 统一算法接口

两种算法仍使用相同调用方式：

```matlab
ccgResult  = run_algorithm('CCGDE3',problem,options);
nsgaResult = run_algorithm('NSGA2',problem,options);
```

`windflo_evaluate_population` 会自动读取 `problem.representation`：

- `continuous`：调用 `windflo_decode_continuous`；
- 没有该字段或为 `discrete`：继续调用原 `windflo_decode`。

## 5. CCGDE3 分组

连续版不再对200个坐标分量随意分组，而是以一台风机为最小单元，保证 `xi,yi` 一直在同一组。默认的10组对应每组10台风机。

## 6. 数据目录

```text
results_large_scale/          原离散版正式数据（保留）
results_continuous_validation/ 连续版100风机快速验证数据
results_continuous/            运行 main_continuous 后生成的正式数据
```
